How it was built

1. Create data10×12 array of random sales between 40,000 and 1,20,000, seed 42 so results repeat.arange · random · reshape
2. SliceQuarters as column ranges, single stores as rows.sales[:, 0:3] · sales[2, :6]
3. MaskConditions combined with &, |, ~; np.where lists the matching records.(sales > 1e5) & festive
4. Fancy indexPick stores by list and the best months by sorted index.argsort · np.ix_
5. TargetsA target that rises each month, compared to all stores at once.linspace · broadcasting
6. Query engineOne function that applies sales range, store and month filters together.query()
def query(min_sales=None, max_sales=None, store_names=None, month_list=None):
    mask = np.ones(sales.shape, dtype=bool)
    if min_sales is not None:   mask &= sales >= min_sales
    if max_sales is not None:   mask &= sales <= max_sales
    if store_names is not None: mask &= np.isin(stores, store_names)[:, None]
    if month_list is not None:  mask &= np.isin(month_names, month_list)[None, :]
    r, c = np.where(mask)
    return [(stores[i], month_names[j], int(sales[i, j])) for i, j in zip(r, c)]
